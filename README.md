# Cryptocurrency Market Analysis 

## 1. Introduction
This report provides an analysis of the top 50 cryptocurrencies by market capitalization, using live data fetched from the CoinGecko API. The analysis includes key metrics such as market capitalization, trading volume, and 24-hour price changes.

## 2. Data Overview

The dataset includes the following key attributes for each cryptocurrency:

•	Cryptocurrency Name

•	Symbol

•	Current Price (in USD)

•	Market Capitalization

•	24-hour Trading Volume

•	24-hour Price Change (%)

The data was fetched in real-time and updated every 5 minutes to ensure the most accurate insights.
